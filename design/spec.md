# Second Room design specification

Reference: concept.png, generated specifically for this project by adapting the owner-approved Roomcraft design. Cream #f6f5f0, forest #183c35 / #285641, Manrope/system sans, continuous white inspector, large original 3D room at left, original model thumbnails rendered from geometry, understated three-metric strip and a full-width next-action band.

Exact primary copy: Second Room; Plan a room. Keep what works.; Reset; Export plan; A new space. Less new stuff.; See what you can reuse before you buy.; Your reuse plan; Reuse planned; Budget needed; Confirmed reused; The next step; View checklist.

Functional extensions: collapsible condition/position/notes controls, a real checklist dialog, plan import and portable export, method/source page, live status and keyboard accessibility. Sample initial metrics match the concept: 3/5 direct reuse, EUR 210 budget, zero confirmed outcomes. Repair is separate from direct reuse, and all completion is self-reported. The displayed repair action deliberately avoids prescribing a specific repair before inspection. The scene uses original procedural geometry, not the raster concept. Mobile stacks the scene and inspector.
